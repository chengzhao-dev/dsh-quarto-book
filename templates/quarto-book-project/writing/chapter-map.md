# 章节对照

本文件只收通用技能不知道的事实：每一章的文件名、类章或能力章、关键对象、
YAML `title` 与二级标题。类章与能力章的定义、一章一个关键、标题分层与收尾节名
由插件 `writing-quarto` 的 `steps/02-structure.md` 负责，这里不抄。

章节顺序以根 `_quarto.yml` 的 `book.chapters` 为准；下表只用于核对章节骨架。

| 路径 | 类章 / 能力章 | 关键（类或交付物） | `title` | 二级标题（按顺序） |
| --- | --- | --- | --- | --- |
| `content/.../01-....qmd` | 能力章 |  |  |  |
| `content/.../02-....qmd` | 类章 |  |  |  |

## 写作约束

- `title` 与 `_quarto.yml` 及正文 YAML 中的写法逐字一致；类章的 `title` 用读者名，
  不写英文类名，除非关键对象本身只有一个英文名。
- 二级标题是这一章关键的部分，顺序与「关键」一列对应；成员函数可以做三级标题，
  不能做章标题。
- 本表是章题契约：`title`、`关键`、二级标题三列与正文同轮同步；改 title 或任务节
  时同轮改本表，表与正文不一致按章题脱节处理。项目有检查脚本时，让它逐章核对
  `title` 与 `##` 顺序。
- 固定收尾 `常见错误`、`自测问题`、`本章回顾` 不改名，不升成关键。
- 类型章的文件名镜像关键类；改文件名时同轮同步 `_quarto.yml`、本表、`title`、
  已有链接与内容检查脚本里的章关键键，不留旧名孤儿。
