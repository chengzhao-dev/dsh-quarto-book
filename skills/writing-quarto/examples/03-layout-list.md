## 定版式：构造后的成员并列成列表

条文见`steps/07-layout.md`「列表选择」。四个数据成员的初始状态被写进同一句，读者要自己拆开「状态面板为空，轮到甲方，结果进行中，历史也为空」；改成引导词列表后，各项共享的访问规则留在列表后的一句，不拆进每一项。同一页教怎么写注释的 callout 一并删除：注释怎么写、行尾先写什么、`///` 与 `@` 标签怎么分工只留在 `.agents`（条文见`steps/03-blocks.md`）。

**定版式（示例章 `Game()` 构造后的块后段与 callout）：**

````text
不佳（四个初始状态压进一句；callout 整段是编写指令，「属于第二句信息」「由正文交代」都在教作者写注释）：
`Game()` 默认构造后，状态面板为空，轮到甲方 操作，流程结果为进行中，历史也为空。状态面板、轮次、结果和历史都收在对象内部，外界只能通过读取函数查看，改动只发生在尝试操作的函数里。历史按操作先后排列，查询历史就能回放一次流程。

::: {.callout-note title="成员注释先写保存的对象"}
行尾注释先写成员保存的对象，`history_` 就写“本局操作记录”。至于按什么顺序排列，属于第二句信息，由正文交代，不要让只写顺序的说明代替对象名。
:::

改写（导语一句 + 列表四项 + 共享规则与历史顺序各留一句；callout 整段删除）：
`Game()` 默认构造之后，四个数据成员是下面这样：

- **状态面板**：`board_` 是空状态面板。
- **轮次**：`current_player_` 为 `Player::kFirst`。
- **结果**：`result_` 为 `Result::kInProgress`。
- **历史**：`history_` 还没有操作。

四项都在对象内部，读取函数可以查看，只有尝试操作的函数会改它们。`history_` 按操作先后排列，查询它就能回放这一次。
````

判定信号：一句里顿号、逗号并列三个以上数据成员且各项状态不同；callout 在教行尾先写什么、第二句交给谁，而不是告诉读者状态面板上发生了什么。

## 列表字数带失衡

同列各项字数相差两倍以上或引导词相差 4 字以上时，扫读节奏断裂（计量口径见`steps/07-layout.md`「列表选择」）。以 示例章失败策略列表改稿前为对照：

```text
不佳（引导词长度差 6 字，长项夹带流程频次旁白）：
- **出界坐标**：说明调用方算错了行列，没有可返回的数据项，`GetCellState` 直接抛出 `std::out_of_range`。
- **目标数据项已被占用**：在流程里随时会发生，`PlacePiece` 返回 `false`，状态面板保持不变，调用方另选数据项就行。

改写（引导词收进同一字数带，删去可由正文覆盖的频次旁白）：
- **出界坐标**：说明调用方算错了行列，没有可返回的数据项，`GetCellState` 直接抛出 `std::out_of_range`。
- **数据项被占用**：`PlacePiece` 返回 `false`，状态面板保持不变，调用方另选数据项就行。
```

判定信号：同一列表内最长项冒号后字数 ≥ 最短项 × 2，或引导词相差 ≥ 4；长项的第二句删掉后主线仍闭合。章级定稿对照见`examples/08-appendix.md`「列表项长度均衡定稿」。

## 公式与换算讲解段

公式定义、原理和代入示例能不能压进一句：不能，一句只做一件事。下标换算的算式要不要再排展示公式：不要再排，算式的载体就是围栏里与源码相同的那一行。以 示例章换算一维下标节改稿前为对照。缺陷三类：一句散文同时塞下取值、跳过整行和算术结果；导语把公式塞进反引号；图前段把图已标注的下标区间再念一遍。此外，`return` 已经是 `row * kCols + col` 时，正文另排两块居中公式——第一块把定义再写一遍，第二块把代入再算一遍——同样判为不合格，算式的载体就是围栏里与源码相同的那一行：

```text
不佳（导语反引号塞公式；代入一句同时含取值、跳过整行与得数；return 行之外另排两块居中公式）：
数组只用一个下标给九个数据项编号，`Board` 按 `row * kCols + col` 把行列坐标换算成下标，换算写在 `state.cpp` 里：
（ToFlatIndex 定义）
以 (1, 2) 为例，row 是 1，col 是 2，row * kCols 先跳过第 0 行占去的下标 0–2，再加上列偏移 col，结果是 1 * 3 + 2 = 5。

$$
\mathrm{row} \times \mathrm{kCols} + \mathrm{col}
$$

(1, 2) 里 row 是 1，col 是 2，kCols 是 3，先跳过第 0 行的 3 个格子，再数到列号 2：

$$
1 \times 3 + 2 = 5
$$

改写（导语点名函数与 `cells_` 的数组下标并点明实现文件；围栏后同一段五句，一句一个动作，后句接住前句的得数）：
`Board::ToFlatIndex` 把 `row` 和 `col` 换成 `cells_` 的数组下标，实现写在 `state.cpp` 里：
（ToFlatIndex 定义，末行即 return (…* kCols) + …）
`cells_` 的数组下标按行排开，第 0 行占 0、1、2。一行有 `kCols` 个数据项。第 `row` 行从下标 `row * kCols` 开始，前面 `row` 个整行已经跳过。列号 `col` 从 0 起，加在这一行的起点上。坐标 `(1, 2)` 的 `row` 是 1，`col` 是 2，`kCols` 是 3。数组下标是 `1 * 3 + 2`，等于 5。
```

```text
不佳（图前段把图已标注的下标区间再列一遍）：
下面的图把 cells_ 的九个下标排成一行。第 0 行占下标 0–2，第 1 行占 3–5，第 2 行占 6–8。加粗的下标 5 就是 (1, 2) 的换算结果。

改写（图前一句点名得数是哪一个数组下标，不把图里已标的区间再念一遍）：
下面的图按行标出 `cells_` 的数组下标，加粗的是下标 5。
```

判定信号：`return` 行之外另排 `$$` 或行内数学模式；换算句没点名载体（「一个下标」「这个下标」「这次代入」互相指代，或导语用「这个下标」而全句未写出是 `cells_` 的数组下标）；一句里同时出现跳过整行、列偏移、代入数字与得数；公式项列表；导语用反引号扛公式本体；代入段里列号与「第 N 列」混用（列号从 0 起算，「第 2 列」会让人从 1 数起）；图已经标出的下标区间在图前再列一遍。「换算只发生在 `Board` 内部」这类局部实现事实本身合法（见 `language-scope.md` 的「流程交流不绑定媒介与行为刚性表述」的判定信号），多处复述或混进图导览段才违规。换算句式规则见`steps/07-layout.md`「列表选择」换算条。

## 多命令讲解改列表

以 示例章构建规则节的自动化检查列表为对照；同日二次修订，一段一命令的拆分形态推翻为列表（规则见 `steps/01-task.md`）：

```text

enable_testing() 开启 CTest……。add_test 用 NAME 和 COMMAND……。set_tests_properties 再加一道……。三条命令合起来定义了本章唯一的自动化检查……。

改写（列表：行内代码标识符 + 一句职责，描述从简）：
- enable_testing()：开启 CTest，此后注册的测试才能被发现和运行。
- add_test()：把可执行目标注册成名为 app_smoke 的测试。
- set_tests_properties()：要求输出匹配 Hello, World!。
```

总结句「三条命令合起来定义了本章唯一的自动化检查」与节首句「同一份构建规则还注册了本章唯一的自动化检查」重复，按同义反复禁令删除；节首句同时充当列表引言。段间衔接见 `steps/01-task.md`。
