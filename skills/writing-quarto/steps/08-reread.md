# 第 8 步：回读并退回

产出：一份现象与步骤的对照结论，以及要退回哪一步的清单。

机械项：`verifying-content.py` 扫读者 qmd 与 agents 的 `下一节`/`上一节`、`代码把它写成`、`第二道…防线`、围栏外正文的 `由…完成` 与 `由…确定／体现／界定／表达`；读者正文的 agent 免责腔硬拦，章节页引言两个散文段、段落下限由 `verifying-content.py` 判失败；段内连续分句引入新行内代码标识且无回指的过简断裂信号由 `verifying-content.py` 记 WARN（不追清零）。句子模块切分由 `verifying-content.py` 对扫描范围内的 qmd 全量执行，只印切分计数与失败行，失败收三类高精度信号（类型接线句、「接着看／第 N 个枚举」改口、全称被下一句否定）；段中心写不出与对话件数不做正则，留给步骤与案例。

### 润色流程：沿着步骤走

润色任务沿 `SKILL.md` 的写作步骤执行，从定任务走到通过检查，跳步视为未完成；判定标准见 `steps/06-wording.md`。书根 `README.md` 与 `README.en.md` 是仓库说明页，按 `SKILL.md` 的例外只走第 5–8 步，这个例外优先于本步的跳步判定。两种走法共用 1–9：**增量润色**保持最小改动，只改判为不合格的句子，不做风格重塑；**全章重构**按 `SKILL.md`「两种走法」走——章级（1–2）先定删留不动句子，节级（3–4）只拆块和段，句级（5–7）逐句拆开再写回去，该层全部重组，不走最小改动。执行时遵守定段落节的既有判定：分句骨架在定句子判为不合格，不在定段落里顺手改句子。

**先切模块，再套规则。** 任何一步动笔前先把文本切成单位，围栏、YAML 与链接 URL 跳过（脚本按同一口径统计，计数见 `verifying-content.py` 输出）：

- **章**：标题到下一个 `##` 之前。只做定任务、定结构。
- **节**：`###` 到下一标题。只做主线与标题对齐。
- **自然段**：空行隔开的散文。只做一段一中心、概念负荷、块后还有没有新信息。这一步不改分句措辞。
- **句子**：段内按「。！？」切开。只做一句一中心、拉链、句内骨架、和下一句是否互相否定。
- **列表项**：`-` 或有序编号。只做一项一中心、平行、字数带。不把列表项当散文拉链改。
- **表格单元格**：管道表。一表一事；格里写事实，不写第二篇散文。
- **块**：导语、围栏、块后、Callout。围栏不是句子；块后新信息的判定见 `steps/03-blocks.md`。

「一次对话」不与这些单位并列成切分单位：脚本切得出标题、空行、句号、列表和表格，切不出「一次说话」。它只留在 `steps/05-sentences.md`「一次对话」的判定里——定段落先问这段有几件内容，再决定删、拆或切成几次说话；定句子才改措辞。

1. **普查建账**：`git ls-files` 按扩展名分类，列出全部含中文自然语言的文件（跳过机器生成物与二进制）。台账写 `temp/`（不入库），逐文件记「审读状态／修改数／备注」；任务结束前每行落到「已审」，无问题也记「未发现」。覆盖率由 `verifying-content.py` 的「中文体检」项背书：台账文件总数与脚本输出的载体组计数对不上即为漏审。
2. **沿步骤逐篇走**：从定任务到通过检查，每步只改该步判为不合格的句子；后一步发现前一步没做完，退回那一步，不在当前步补结构。某句只在定用词失败，就不重写它的结构；某段在定句子失败，先改骨架，再让定用词看一遍。已合格的句子不重润。
3. **改写**：最小改动，只改判为不合格的句子，不做风格重塑。改写不破检查：qmd 导语 token 与句数、段落篇幅、禁用词由 `verifying-content.py` 把关；中文文件保持 UTF-8 无 BOM、LF。代码围栏逐字摘自源文件，本步骤不改围栏；同源复制文件改一处同步其余并 diff 比对。改动触及知识库案例引用句时先 grep 案例文件再同步。
4. **验收同步**：按改动域跑校验（qmd → `verifying-content.py` + `checking-links.py`；有项目技能时按它列出的命令，跨域收尾跑它的全量 profile）。检查次数与停手见 `steps/09-check.md`「完成判据」。

## 情况

### 情况：现象落在更早的步骤

信号表说现象属于哪一步，就退回那一步改，不在第 8 步改写。一次只退一步，改完重新回读。

### 情况：章级低频问题

个别章才出现的版式与语气问题看 `examples/08-appendix.md`，它是低频对照，不是新的步骤。

### 情况：对照改前文本

回读时把改后稿和改前稿并排看，专查三件事：改后多了原文没有的事实、数字、命令、性能结论或引文；原文有、改后丢了且读者任务需要的信息；原文的「可能」「通常」「在本书里」被改成确定说法。命中就恢复原文，再按信号表退回对应步。增量润色与全章重构都要对照：全章重构允许删除与换序，不允许改事实和确定性。
