# 交叉引用

本文件是 Quarto 交叉引用语法的唯一出处：标签怎么写、正文怎么引、书里编号从哪来。什么时候值得引用、引用读起来是否自然，仍归 `steps/` 与 `writing/06-prose.md`。

## 标签与引用

| 对象 | 标签写法 | 正文引用 | 渲染示例 |
| --- | --- | --- | --- |
| 章或节 | `## 标题 {#sec-name}` | `@sec-name` | 第 3 章、3.2 节 |
| 图 | 围栏内 `#| label: fig-name`，或图片 `![说明](path){#fig-name}` | `@fig-name` | 图 3.1 |
| 表 | 表题 `: 说明 {#tbl-name}` | `@tbl-name` | 表 3.1 |
| 公式 | `$$ ... $$ {#eq-name}` | `@eq-name` | 式 3.1 |
| Callout | `::: {.callout-tip #tip-name}` | `@tip-name` | 提示 3.1 |

前缀决定对象类别：`sec-`、`fig-`、`tbl-`、`eq-`、`lst-`、`alg-` 是常用类别；定理类用 `thm-`、`lem-`、`cor-`、`prp-`、`cnj-`、`def-`、`exm-`、`exr-`、`sol-`、`rem-`；Callout 用 `nte-`、`wrn-`、`imp-`、`tip-`、`cau-`。前缀写错时 Quarto 不把它当可引用对象，正文只会留下字面 `@...`。

标签在同一本书里必须唯一，且全部小写、避免下划线；大小写或下划线变化会改变生成的锚点。改名标题等于改锚点，改完要重新核对所有 `@sec-` 与页内链接。

`number-sections: false` 只让标题不显示编号，`@sec-` 仍按交叉引用索引渲染「第 N 章」或「N.M 节」；需要不编号的章时用 `.unnumbered`。

## 书里的编号

- 图和表在书里默认带章号（第 3 章的第二张图渲染为「图 3.2」）；`number-sections: false` 只关闭标题编号，不关闭图/表编号，`@fig-`、`@tbl-` 仍可解析。
- `.unnumbered` 章不产生章号，章内图/表编号回到章内计数（如「图 1」）；同章引用可用，跨章引用前先看渲染结果，不假定仍带章号。整本关闭编号只影响标题，前言、参考文献和普通链接仍按上面的规则处理。
- `number-depth` 控制编号到第几级标题，`toc-depth` 独立控制目录展开深度。两者都是 **format 级选项**：放在 `_quarto.yml` 顶层或 `format: html` 下，不能放进 `book:`。
- 标题里的编号由 Quarto 生成，不手填；手填序号在增删小节后会与交叉引用和目录一起错位。

## 引用形式

- `@sec-x` 按标题级别渲染成「第 N 章」或「N.M 节」；`[-@sec-x]` 只留编号；`[Chapter @sec-x]` 可换自定义前缀。
- 纯 HTML 书可以用普通链接 `[说明](file.qmd)` 或 `[说明](file.qmd#anchor)`；要出 PDF、Word 或打印稿时必须用 `@` 引用，读者才能看到编号而不是不可点的链接。
- 引用前确认目标存在；引用句要能独立读懂，不写「见上文」「如下图所示」。

## 项目级取舍

是否给章节标题加 `{#sec-...}`、何时值得用 `@fig-...` / `@tbl-...` 编号引用，属项目级选择，由书的项目技能登记；本文件只讲语法。
