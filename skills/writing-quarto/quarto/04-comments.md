# 注释：qmd、YAML、TOML、SCSS 与 CSS

> 速查：qmd 不写声明注释 · YAML 的 `#` 只写为什么 · TOML 一项一条、句式「对象：条件时，后果」 · SCSS 区域标记不可删 · 纯 CSS 只用 `/* */` · 不写 `///` 与 `@param`

本文件只管 Quarto 书里各类文件的注释写法。C++、CMake、shell 与 Python 的注释归项目自己的 C++ 流程，本技能不复述；正文与代码围栏的关系见 `steps/03-blocks.md`「内容块前后的闭环」。

## 术语

- 注释里第一次出现的项目行话先写通用说法；「一次落子」就写全，不缩成行话简称。不假定读者读过正文或代码。
- 同一文件的注释只用一个叫法；简称在定义处出现一次，后面不再换词。

## qmd 正文

- `.qmd` 不设文件头声明注释，也不写函数、参数或返回值注释。章节的任务、边界和读者对象由导语与二级标题承担，注释不重复。
- 正文里不保留被注释掉的旧段落、旧链接或旧围栏。要留历史就交给 Git，不在源文件里堆注释。
- 围栏与源注释的分工（逐字摘录、不解释注释、文件头不进正文）见 `steps/03-blocks.md`「摘录与源文件注释」；本文件只留 qmd 注释风格。

## YAML

- `#` 只写「为什么这样取值」，不把键名翻译成中文，也不复述默认值。
- 能由 `_quarto.yml` 的键本身说清的，不写注释；同一取值只在一处解释，其他文件引用该处。
- front matter 里不写分隔线式注释（`# --- 标题 ---`）；标题就是 YAML 的 `title:`。
- 注释紧贴被说明的键，放在上一行；不放在行尾挤占宽度。

## TOML 与项目配置

`config.toml` 这类工具链配置一个键一项：注释紧贴键的上一行，键与注释之间不插空行，也不写行尾注释。

- 句式「对象：条件时，后果。」：全角冒号，句号结尾；对象名与键名对得上，必要时加限定词（解释器、包、命令行工具），不造「Quarto Python」这类歧义复合词。
- 条件写清比较对象，如「解释器版本」「已安装的 Quarto」；不用「它」「此文件」这类要靠上一句猜的代词。
- 后果写清谁报错、报什么：「检查脚本报错退出」「渲染报错退出」；`sed` 取值、CI 步骤这类实现细节不写进注释。
- 同类键取同一句式，便于并排核对；不复述键名与默认值，不写策略段，不指向文档路径。
- 需要交代文件整体用途时，首行写一行标题，其后空一行；标题不复述各键。

正例（书仓 `config/config.toml` 全文：一行标题、四条键注释与分组空行）：

```toml
# 本仓 Python 与 Quarto 的运行时配置。

# Python 解释器的完整路径：解释器不存在或不可执行时，检查脚本报错退出。
python_path = "D:/ProgramData/miniforge3/python.exe"
# Python 解释器的最低版本：解释器版本低于此值时，检查脚本报错退出。
python_min_version = "3.12"

# Quarto 渲染 Python 代码块所需的 Python 包：缺包或版本过低时，渲染报错退出。
quarto_python_packages = [
  "ipykernel>=6.29",
  "jupyter>=1.0",
  "nbclient>=0.10",
]
# Quarto 的最低版本：已安装的 Quarto 低于此值时，检查脚本报错退出。
quarto_min_version = "1.10.19"
```

反例：`# python 路径` 复述键名；`# 版本低于此值时报错退出` 缺比较对象与执行者；`# CI 用 sed 取值` 写实现细节。

## SCSS

- Quarto 的三段区域标记必须原样保留，不能删除、改写或合并：

  ```scss
  /*-- scss:defaults --*/
  /*-- scss:rules --*/
  /*-- scss:mixins --*/
  ```

  区域标记是 Quarto 注入变量的边界，删掉后变量会落到错误的作用域。
- 变量分组用 `//` 单行注释；跨行说明用 `/* */`。
- 不写「这段设置颜色」式复述；注释只写取值理由或与另一处令牌的同步关系。

## CSS

- 纯 CSS 只接受 `/* */`；`//` 不是合法 CSS 注释，会被当成选择器或声明而报错。
- 不在 CSS 里写 `///` 文档注释、`@param`、`@return` 或 Doxygen 标签；这些是源码声明注释的写法，主题资产不用。
- 注释只解释「这条规则为什么存在」或「和哪个令牌联动」，不逐条翻译属性。
- 被禁用的规则用注释说明原因后直接删掉，不保留大段注释掉的旧样式。

## 编码与行尾

所有文本文件按 `quarto/02-encoding.md` 保存为 UTF-8 无 BOM、LF；`.bat` 与 `.cmd` 例外，用 CRLF。
