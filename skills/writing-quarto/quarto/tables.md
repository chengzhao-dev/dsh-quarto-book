# 表格

表格只回答「多个对象按同一组属性怎么比较」。并列步骤用有序列表，两个对象两三条区别用句子；表格一旦只装一两列信息，读者会把它当成大号列表读。

## 何时写表

- **保留**：三个及以上对象、且每条对象都有两项以上可比属性；属性在各行里位置相同，读者能纵向对照。
- **改列表或句子**：只有一两列、或右侧大量留白；对象之间没有共同属性，只是并列罗列。
- **不重复代码**：接口表只写签名读不出的差异（返回什么、边界怎么处理），不把 `@param`、`@return` 再抄一遍。

## 固定写法

一张表由三段构成，缺一段就是块悬空：

1. **表前导语**：一句完整的话，点名要比较的对象与属性，说明为什么此刻看这张表。不写「如下表」「见下表」式空引导，不写「N 个接口」式元计数。
2. **表格本体**：表头写属性名，首列写被比较的对象；一行一个对象。
3. **表后结论**：一句读者该取走的判断，如共同约定、例外或分类依据。不复述格子里的字面值。

代码块、图、列表与表格之间不能直接相接：中间至少隔一段正文，写清两者关系（代码块给出定义，表格归纳接口差异）。连续两个盒子会让读者分不清边界，也只能靠滚动定位。

## 表头与列宽

- 表头由主题统一加粗、加浅底色：`.table thead th` 已设 `font-weight: 700`。正文不写 `**接口**` 式加粗，也不写「表头加粗」说明。
- 列宽只给**相对比例**，不给像素：

  ```markdown
  | 接口 | 返回 | 边界 |
  | --- | --- | --- |
  | `GetCellType` | 坐标处的 `CellType` | 越界时抛出 `std::out_of_range` |
  : {.responsive tbl-colwidths="[24,30,46]"}
  ```

  比例按内容分配：名称与接口列 18–26，返回列 22–32，说明列 34–50，三项合计 100。三列以上时最长列不超过 55，避免其余列被挤成一条线。
- 表格与代码块同宽：主题用 `table-layout: fixed` 吃上面的比例，`width: 100%`、`box-sizing: border-box` 与左右零外边距让两者外框对齐；单元格 `0.7rem 1.25rem`，首列不贴边。文本列左对齐，数字列右对齐，表头跟随该列。
- 宽表在表属性里加 `.responsive`（Quarto 内置类）：Quarto 生成外层 `.table-responsive` 滚动容器，主题在该容器里改回按内容宽度排布，内容超过正文栏时才出现横向滚动。窄表可省。
- 不写固定宽度（`{width=...}`、`style="width:..."`），也不覆盖 `table-layout`；比例之外的几何由主题负责。
- 长单元格先改文案：删重复修饰，把条件与结果按「条件 + 结果」排成一句。仍长时允许格内折行，`overflow-wrap: break-word` 已由主题处理。

## 单元格

- 一格一个事实，对象先行。不写「名词：一句」的伪列表，列已经分出属性名。
- 行内代码只放读者要输入的标识符或类型名；一格最多两个，多了会把列撑宽，也让比较点被代码淹没。
- 空值与未知写「无」或「不判断」，不写 `-`、`N/A`。
- 列对齐由管道表的 `---:` 标记决定，主题只给默认左对齐；不要在单元格里手动空格对齐。
- 中英混排留半角空格，标点用全角，规则见 `quarto/prose.md`。

## 表题与引用

- 需要正文引用时加表题：表格下一行写 `: 表 3-1 棋盘接口的返回与边界 {#tbl-board-api}`，表题随主题显示在表上方、小一号。
- 表题只写对象与内容，不写「如下表」「本表说明」。
- 同一页表题编号连续；正文引用写「表 3-1」，不写「下表」。

## 正反例

**反例**（代码块后直接接表，表前没有过渡）：

```markdown
| 接口 | 返回 | 边界 |
| --- | --- | --- |
```

**正例**：

```markdown
三个只读接口都只回答棋盘状态，区别在返回什么、越界怎么处理：

| 接口 | 返回 | 边界 |
| --- | --- | --- |
| `GetCellType` | 坐标处的棋盘格子类型 | 越界时抛出 `std::out_of_range` |
| `IsCellEmpty` | 空格子返回 `true` | 越界或已有棋子时返回 `false` |

需要提前判空的调用方用 `IsCellEmpty`，已经做过范围检查的调用方用 `GetCellType`。
```

## 检查清单

- [ ] 表前有导语、表后有一句结论，两句都不复述格子内容。
- [ ] 代码块、图、列表与表之间隔了一段正文。
- [ ] 表头没有手写加粗；列宽是相对比例，最长列不超过 55%；宽表加了 `.responsive`。
- [ ] 一格一个事实，没有「名词：说明」和手动空格对齐。
- [ ] 短表已改回句子或列表。
