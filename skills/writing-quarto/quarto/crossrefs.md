# 交叉引用

本文件是 Quarto 交叉引用语法的唯一出处：标签怎么写、正文怎么引、书里编号从哪来。什么时候值得引用、引用读起来是否自然，仍归 `steps/` 与 `quarto/prose.md`。

## 标签与引用

| 对象 | 标签写法 | 正文引用 | 渲染示例 |
| --- | --- | --- | --- |
| 章或节 | `## 标题 {#sec-name}` | `@sec-name` | 第 3 章、3.2 节 |
| 图 | 围栏内 `#| label: fig-name`，或图片 `![说明](path){#fig-name}` | `@fig-name` | 图 3.1 |
| 表 | 表题 `: 说明 {#tbl-name}` | `@tbl-name` | 表 3.1 |
| 公式 | `$$ ... $$ {#eq-name}` | `@eq-name` | 式 3.1 |
| Callout | `::: {.callout-note #nte-name}` | `@nte-name` | 提示 3.1 |

前缀决定对象类别：`sec-`、`fig-`、`tbl-`、`eq-`、`lst-` 是常用五类；定理类用 `thm-`、`lem-`、`cor-`、`prp-`、`cnj-`、`def-`、`exm-`、`exr-`、`sol-`、`rem-`；Callout 用 `nte-`、`wrn-`、`imp-`、`tip-`、`cau-`。前缀写错时 Quarto 不把它当可引用对象，正文只会留下字面 `@...`。

标签在同一本书里必须唯一。改名标题等于改锚点，改完要重新核对所有 `@sec-` 与页内链接。

## 书里的编号

- 图和表在书里自动带章号（第 3 章的第二张图渲染为「图 3.2」），前提是所在章参与编号。
- `.unnumbered` 章不产生章号；整本关闭编号（`number-sections: false`）时也没有章号。两种情况下章内的图、表都无法按章号交叉引用，这类章只放前言、参考文献，或改用普通链接。
- `number-depth` 控制编号到第几级标题，`toc-depth` 独立控制目录展开深度。两者都是 **format 级选项**：放在 `_quarto.yml` 顶层或 `format: html` 下，不能放进 `book:`。
- 标题里的编号由 Quarto 生成，不手填；手填序号在增删小节后会与交叉引用和目录一起错位。

## 引用形式

- `@sec-x` 按标题级别渲染成「第 N 章」或「N.M 节」；`[-@sec-x]` 只留编号；`[Chapter @sec-x]` 可换自定义前缀。
- 纯 HTML 书可以用普通链接 `[说明](file.qmd)` 或 `[说明](file.qmd#anchor)`；要出 PDF、Word 或打印稿时必须用 `@` 引用，读者才能看到编号而不是不可点的链接。
- 引用前确认目标存在；引用句要能独立读懂，不写「见上文」「如下图所示」。

## 本项目的取舍

`cpp-board-games` 是纯 HTML 中文书，章节标题不写 `{#sec-...}`，跨章引用用章节标题链接。图、表确实需要编号引用时才写英文标签 `{#fig-...}`、`{#tbl-...}`，正文用 `@fig-...`、`@tbl-...`；其余场合不为了「可能要用」预先加标签。这条是项目级选择，不改变上面的通用语法。
