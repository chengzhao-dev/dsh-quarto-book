# writing-quarto

本技能负责 Quarto Book 的读者正文：`content/**/*.qmd`、`index.qmd` 与 `_quarto.yml` 的章节结构。主题样式走 `designing-theme`，C++ 源码走 `developing-cpp`，书里的业务事实由项目技能提供。

## 适用场景

- 新建、改写、润色或只读审查章节正文。
- 调整章题、二级标题、内容块顺序、段落、句子、用词与版式。
- 核对正文里的代码围栏与源文件是否一致。

不适用：主题颜色、字体、导航与页面样式；只改 `.cpp`；书里项目的业务知识本身。

项目有 `.agents/skills/quarto-book-project/SKILL.md` 时，先读本技能，再读项目技能，只按它指向的章节对照与术语表读；没有就跳过，不猜书名、章节名与术语。

`README.md` 与 `README.en.md` 只走第 5–8 步：它们是说明页，不套任务与结构骨架，不写「常见错误」「自测问题」，不调 `quarto_render_check`；发现问题只退回第 5–7 步。`CHANGELOG.md`、`LICENSE`、`AGENTS.md` 不在写作范围。

## 三种操作

一次只选一种，`mode` 只填一个；范围（单点、整章、全书）是任务属性，不单独占一个操作。只读审查不改文件，不调渲染与回执。

| 操作 | 什么时候选 | 从哪步进 | `mode` |
| --- | --- | --- | --- |
| 写作（起稿） | 缺任务、结构、块或事实 | 第 1 步；新章走到第 4 步 | `write` |
| 改写 | 事实与行为不变，块段、顺序或篇幅不对 | 从被打破的步重走，可到第 9 步 | `rewrite` |
| 润色 | 结构已对，只改句子和用词 | 第 5–8 步；段像清单先走第 4 步 | `polish` |

判不准时先看缺哪一层：缺事实、动作或结果选写作；块段顺序走不通选改写；只差句子与词选润色；都不缺是只读审查。越界信号与三种手法见 `writing/01-operations.md`。

三种操作共守：不新增事实、数字、命令、结论、引文与出处；不把「可能」「通常」「在本书里」改成确定；保留否定、条件、范围、时间与归属；围栏里的代码、命令、路径、URL 与 YAML 不改。润色只改句子与词；改写可删段换序，但不发明事实。只读审查按九步逐条报告行号、规则出处与改法。

## 加载规则

- 一次激活只做一类文件：章节或主题。写章节时只打开项目技能或 `_quarto.yml` 点名的章节；围栏注释与源文件不一致时回源改围栏，不读无关实现。
- 只开本文件、当前一步与该步点名的一个文件；第 8 步只开 `steps/08-reread.md`。同轮不把同号案例、其余步骤和条文一起打开。
- 判不准才开步骤点名的 `examples/` 案例；`writing/` 是完整条文，只在排错、整书重构或步骤明确指向时打开。
- `quarto/` 只在排图、查渲染、写围栏或核对 qmd 语法时按需打开，不整目录读。
- 同一文件最多退回上一步一次；第二次仍失败就停在检查输出上，不重走整段。
- 句子与条文、项目技能或既有正文冲突时，先列冲突位置、原句与出处，由用户选一条；不自行取舍或默认采用计划。
- 不探测同 profile 的其他插件，也不把它们写成依赖；子会话按自己的 cwd 重新判定门禁，不把技能正文塞进子代理提示。

改多章或排目录时，先读 `writing/03-book-journey.md`：先定全书主线与章节次序，再逐章判操作走对应步骤，最后做全书一致性回读。单章与整书共用同一套九步，不另造章节规则；项目有章节表时以项目表为准。

## 九步地图

操作定入口，域定层次；九步按四域分：内容 1–2，结构 3–4，措辞 5–6 与 8，版式 7（整书字体、间距与页面样式归主题）。跨域按内容→结构→措辞→版式推进，前步落定再进。

| 步 | 名称 | 产出 | 文件 |
| --- | --- | --- | --- |
| 1 | 定任务 | 读者做完能完成的一件事 | `steps/01-task.md` |
| 2 | 定结构 | 页面骨架、二级标题与篇幅 | `steps/02-structure.md` |
| 3 | 排列内容块 | 导语、围栏、收束与 Callout 的次序 | `steps/03-blocks.md` |
| 4 | 定段落 | 一段一个关键，句间接住新信息 | `steps/04-paragraphs.md` |
| 5 | 定句子 | 主语是执行者，一句一动作 | `steps/05-sentences.md` |
| 6 | 定用词 | 术语、语态与语气统一 | `steps/06-wording.md` |
| 7 | 定版式 | 标点、中英混排、列表与加粗 | `steps/07-layout.md` |
| 8 | 回读并退回 | 按现象找到该退的步 | `steps/08-reread.md` |
| 9 | 检查与渲染 | 内容与链接检查，HTML 可用 | `steps/09-check.md` |

### 入口表

先开本文件与当前一步，再按需从下表开一类：

| 要打开的东西 | 路径 |
| --- | --- |
| 当前一步 | `steps/` |
| 跨步条文 | `writing/` |
| 案例 | `writing/examples/` |
| qmd 语法、图与渲染 | `quarto/` |
| 正文检查 | `scripts/` |
| 篇幅预算 | `token-budget.md` |

## 文件职责

- `steps/`：每步的唯一权威；同一事实不在本文件复述。
- `writing/`：跨步骤的完整条文（操作、优先级、整书旅程、人物、可读性、散文、重构）。
- `writing/examples/`：案例；只开步骤点名的一份。
- `quarto/`：qmd 语法、表格、图、mermaid、终端、编码、渲染与作者工具。
- `token-budget.md`：篇幅预算的唯一出处。
- `scripts/`：内容、链接、混排与结构检查。

## 完成判据

- [ ] 本轮点名的文件走完它对应的步骤；不要求九步全走。
- [ ] 检查命令退出码为 0；项目有检查命令就按它跑，没有就跑本技能 `scripts/` 下的检查。
- [ ] 新人能按正文独立完成任务：前置、动作、结果与失败出口齐全，术语首用有解释；清单见 `writing/05-readability.md`。
- [ ] 混排自查通过：`scripts/checking-prose.py --root <book>` 无高置信问题。
- [ ] 调 `quarto_render_check`：`dry_run: true` 最多 2 次，确认 `safe_to_render`；`dry_run: false` 最多 1 次，确认 `html_report.usable` 为 true。不手跑 `quarto render`，也不截图 PNG。
- [ ] 收尾调用一次 `quarto_pass_report`：`skill` 填 `writing-quarto`，`mode` 填 `write`、`rewrite` 或 `polish`，改动次数、未改项与检查结论照实填。卡片就是回执，回复里不再复述；没改也传 0，当前文件不是章节时传 `executed: false`。
- [ ] 只读审查：不改文件，不调 `quarto_render_check`、`quarto_pass_report`，报告写清行号、规则出处与改法。
