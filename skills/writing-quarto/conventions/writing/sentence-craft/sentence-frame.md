# 句子的结构规则：成分与骨架

六个成分、句内骨架、拉链句、一次对话与代词先行词的基准；断裂与长度边界见 `conventions/writing/sentence-craft/sentence-limits.md`。

## 代词不能代替未写出的对象

「这个／这些／这一步」类代词只在**同句或同一节的上一句已经列出对象名**时合法；对象名只出现在后面的 `###`、只出现在代码围栏、或只出现在另一道自测题里，都算没有先行词。判定以整篇 qmd 为范围，按标题切开后再看代词前面有没有对象名，一句摘出来不能判。段内回指不在此列：上一句已写出「数量」，下一句写「这个数量」仍然合法（given-new 的复用分支）。

- **自测题干**是合上书的一问，只看本题题干：禁止「这个、那个、这些、那些、哪个、哪些、哪一句、哪一层、哪一行、哪一块」，先写出被问的对象，再用「是多少、会不会、A 还是 B」来问；「什么」允许——它在要一个名字或一句文字，不是指上文没出现的东西。答案折叠里的回指不扫。
- **节首句**不得用代词把后文才展开的内容提前捆成一包：节首以「这些／这个／这一步」作话题、同句又没有列出对象名，即失败。「这一章」「下一章」「这一节」指书的单位，是固定说法，不在此禁令内。
- **已经逐个写出名字之后的回指**仍然合法：如前文小节已写出 `Player`、`Move`、`PlaceResult`、`Result`，后文「这些类型由 `Game` 的四个数据成员使用」保留。

条文与自动检查见 `writing-quarto` 技能 `scripts/verifying-content.py` 的整篇题干/节首检查；步骤挂点：定结构改自测题，定句子改节首与句内代词；对照见`knowledge/cases/chinese-style/sentence-reference.md` 的知识文件「代词不能代替未写出的对象」。换算句里的「下标」不算已经写出的对象；点名规则见`conventions/writing/list-craft.md` 的知识文件「列表选择」换算条。


## 一次对话

面向读者的一次说话只推进一件内容：可以是一句，也可以是紧挨着的两句，但必须沿用同一套说法。对话不是新的切分单位，也不是标题层级：判定挂在定段落和定句子上——定段落先问这段有几件内容、决定删或拆，定句子才改措辞。脚本不统计对话数；自动失败只有下面四条判定里的三类高精度信号（见`conventions/writing/section-flow/block-chain.md` 的知识文件「机械检查」）。

- **一件内容**是读者能单独复述的一件事，例如「这次有没有写进状态面板」。两件内容用顿号或逗号放进同一句，再补「是两个不同的问题」「用两个枚举分开回答」，就是把两次说话写成一次；读者读到围栏前，要回头拿开头的问题去猜后面的编号各指哪个。
- **围栏前的成员列表允许与随后成员注释用词接近；围栏后不再复述**：成员取值列表和成员行尾注释说的是同一批对象，用词相近不是改口；列表之后的数据成员围栏里已写明的信息，块后不再复述。
- **写不出本段中心，或这句与导语、围栏注释同义，就删本段**，不另写替身句。要换对象必须另起段，而且该对象得是本节正在讲的，不能提前交给后文才展开的成员或函数（如 示例章的 `current_player_` 与 `Game::Place`）。
- **后文还讲这件事时，沿用开头的说法和类型名**，不改口成「接着看」「第一个枚举」「第二个枚举」。序数可以指真实位置（示例章「第一个格子」），不能用来给前面并列过的类型、成员、入口、步骤重新编号；格子、行、列和「第二次写入」这类真实次序豁免。改写是每件内容紧挨它自己的围栏，说法从开头保持到围栏。
- **数量词和「这些」必须对着紧接着的名单或围栏**：写「四个入口」「覆盖四类」，下一块就要列出四个名字或四类场景；对不上就改成点名对象（示例章写「读写用 `IsInRange`、`GetCellKind`、`PlaceCell` 和 `IsFull`，`Board()` 只建出空状态面板」，不再说「只留四个入口」）。
- **一句里的全称（全部、所有、唯一）读完下一句仍然成立**；被下一句否定就改范围或删除。**类型接线**（两个逗号分句各自是「成员叫法 + 使用 + 某一章的类型」）若两项都已出现在紧邻导语和围栏里，整段删除，不走「拉链句」的推迟、拆句、一项一行。

条文与自动检查见 `writing-quarto` 技能 `scripts/verifying-content.py` 的句子模块切分；步骤挂点：定段落删段或拆段，定句子改措辞；对照见`knowledge/cases/chinese-style/paragraph-cases.md` 的知识文件「定段落：类型接线段整段删除」、`knowledge/cases/chinese-style/sentence-frame.md` 的知识文件「定句子：两次说话拆成一次对话」与`knowledge/cases/chinese-style/sentence-reference.md` 的知识文件「定句子：数量词对着下一块点名」。

## 句内骨架

写作步骤的定句子步骤。本条管**设计说明**（为什么这样存、这样判定、这样分工）——一段解释代码决策的正文；步骤句、列表项、自测导语不套这条。它不与邻条重复：拆核四步管多核怎么拆段（见`conventions/writing/paragraph-shape/semantic-split.md` 的知识文件「拆核四步」），过简断裂管分句之间的衔接（见本文件「过简断裂禁令」），本条管**分句各自担任什么角色、按什么次序排列**：

- 每个分句只担任一种角色：可观察事实、不变约束、因此作出的选择。次序固定为**事实 → 约束 → 因此选择**；选择句不得出现在依据之前——先写「长度取常量」再补「九个格子」，读者要把因果倒过来读。
- 光有回指不够。后一分句若不是同一谓语的延续，必须写出「因此 / 所以」；删掉关系词后读者仍要自己补因果，判为不合格。可观察事实（「状态面板一共九个格子」）可以在前，读者据此才知道选择成立。
- 「是示例项目规则的一部分」这类只贴类别、不改变下一步的分句删除：它不回答「所以代码怎么办」。
- 一句里用逗号甩出的独立判断，最多留「事实，约束」或「约束，所以选择」一对；第三个判断另起句或删除。单句仍守本文件「句子规则」的 40 字与一动作上限。
- 递进同一核不拆段复述：长度和装下它的数组是同一个核，同段用「因此」接住，不另起一段再说一遍「正好装下」。
- 后续小节专讲的对象，本段不写「由 X 完成」：换算如果由下一小节专讲，本段不提前交接（「换算由下一小节完成」）；块内注释或下节首句已经说出的职责，整句删除。
- 与「对象先行」的对齐方式见`conventions/writing/chinese-quality.md` 的知识文件「句序与段落形态」。

判定信号：设计说明句里选择先于依据；逗号甩出第三个独立判断；分句只贴类别不改变下一步；删掉关系词后因果要读者自补；段末提前交接后续小节的对象。改写对照见`knowledge/cases/chinese-style/sentence-frame.md` 的知识文件「句内骨架：先依据后选择」。类型接线句与被下一句否定的全称按本文件「一次对话」判删留，不按本节改写句内次序。


## 拉链句

一句话里把两组对象两两配对（左组对右组），删掉任一配对，剩下的配对仍能单独成立，原句就是拉链句：读者要按顺序把左组一一配到右组，且两个配对共用同一个判据（如「数据项在哪、上面是什么，分别交给 `Position` 和 `CellKind`」——删掉任一配对，另一配对照样成立）。它不是一个中心，也不是步骤链；现有的「一句一动作」「不提前交接」拦不住它，因为它把两件事合法地写进了同一句。旧「分号双主语」豁免（两个行内代码主语用分号并列，如「`Position` 定位一个数据项；`CellKind` 保存格子的类型」）已废除：这类分号句通常就是拉链句，按本节改写。

三条改写，按顺序选，停在第一条适用的：

1. **推迟**。`##` 有 `###` 时仍按顺序点名子节，但至多两句、一句只点一个对象，只用读者已经看见的白话，不点后文才定义的类型名。类型名留在该 `###` 的块前导语里，紧挨声明。
2. **拆句**。两个都能单独成立的观察分成两句。后句用「因此 / 所以 / 接着」接住前句对象。禁用「分别交给 / 各说一层 / 分别是」。
3. **一项一行**。同一对象的三项及以上取值或属性，放进列表或表格，一项一行。列表项内部也不再用「分别是 A、B 和 C」再拉一次链。

与相邻规则的分工（避免改到不该改的句子）：

- 后一步用到前一步的结果时，写成前后两句陈述，不用「先 / 再 / 最后」连接。
- **同物两处可留一句**：主语只有一个，只是指出声明文件和实现文件；句中再塞第二个任务（接受、拒绝、判定终局）时，第二个任务拆掉。位置句的谓语用「放进」，不用「记住」「保存」「选出」。
- **回顾不按拉链改写**：回顾的条数与形态见`conventions/writing/chapter-structure/skeleton.md` 的知识文件「六段块序列」。
- **块后复述不按拉链改写**：块后复述禁令见`conventions/writing/qmd-element-cases/block-loop.md` 的知识文件「禁止正文复述围栏内注释」（对照见`knowledge/cases/chinese-style/block-after.md` 的知识文件「块后复述注释」）。

判定信号：同一句里用「分别交给」「各说一层」「分别是」连接两组对象；或一句内两组配对删掉任一仍成立。改写对照见`knowledge/cases/chinese-style/sentence-frame.md` 的知识文件「拉链句」；「分别交给」「各说一层」由 `verifying-content.py` 对读者正文硬拦。类型接线句是本节的例外出口：两项都已在紧邻导语和围栏出现时整段删除，不走推迟、拆句、一项一行（见本文件「一次对话」）。


## 六个成分

读者正文围栏外的句子以六个成分为主轴：主语、谓语、宾语、定语、状语、补语。普通句子用不到六个。默认是主语加谓语。谓语支配一个对象时加宾语。定语只修饰主语或宾语里的名词，一层。状语只放在谓语前，一层。补语只放在谓语后说明结果，一层。

一句先标成默认主轴，或标成下表的一种场景。表外的连谓句、兼语句、双宾句、主谓谓语句、名词谓语句、倒装句，拆成默认主轴的两句；同档并句的连谓不拆，异档连谓仍拆。

- 动作支配一个对象：动词谓语句，主语加谓语加宾语。
- 说明状态、没有对象：形容词谓语句，主语加谓语，无宾语。
- 判断类别：是字句。
- 处置读者已经知道的对象，并且写出结果：把字句。对象是新信息时不用。
- 受事是这句话的话题，施事不重要或已在上句：被字句，或受事作主语的动词谓语句。
- 处所里存在、出现或消失某物：存现句，处所作主语。
- 下一句仍是上一句的话题：零形回指，主语不写出。话题已经换了，必须写出主语。

下一句的主语复用上一句的宾语或话题。一句仍只做一个动作，仍不超过 40 字；同档并句一个逗号，整句不超过 40 个汉字。

依据：黄伯荣、廖序东《现代汉语》把主谓句分成动词谓语句、形容词谓语句、名词谓语句、主谓谓语句，常用句式另有把字句、被字句、连谓句、兼语句、双宾句、存现句；朱德熙《语法讲义》把主语看成已知话题；陈平把零形回指定义为上文已出现的事物可以不写出那个词。
