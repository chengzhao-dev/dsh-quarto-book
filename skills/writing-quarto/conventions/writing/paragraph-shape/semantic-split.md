# 段内同义与拆核方法

段内同义堆叠禁令、散文伪标签冒号禁令与拆核四步；段落基础规则见 `conventions/writing/paragraph-shape/rules.md`。

## 段内同义堆叠禁令

一个自然段围绕中心句推进时，同一机制至多给一句展开；再补一句换说法复述同一机制即为段内同义堆叠，主次不清，命中即删辅句或合并。判定信号：

- 段内两句主语不同、谓语同义（如「长度用常量固定」与「长度由常量在编译期确定」），删掉任一句主线仍闭合；
- 中心句之后连续多句都在解释同一个词，没有引入新机制、新对象或新边界；
- 句间只靠「也就是说／换句话说／即」类复述连接，没有因果或递进。

改写形态：中心一句 + 至多一句机制 + 可选一句桥接（引出下一段对象）；需要更多细节时下沉列表、代码块或后续小节，不在段内堆叠。

豁免与边界：

- **换算短句豁免**：换算写成同一段短句各答一个动作，是递进不是堆叠（见`conventions/writing/list-craft.md` 的知识文件「列表选择」换算条）。
- **简洁边界反向保护**：删辅句不得造成电报省略；动作、对象、顺序三要素仍写全（见`conventions/writing/sentence-craft/sentence-limits.md` 的知识文件「简洁边界」）。
- **跨章固定表述不复述判重**：「九个数据项」这类全书统一表述在各章按需出现，不受「同一事实只讲一次」限制。
- **自测答案豁免**：答案可对照题面复述一次再展开。

与「同义反复」（凑字数禁令）的分工：同义反复管跨位置重复（承接句、filename、列表项同讲一个事实）；本条管同一段内的同义展开；命中任一即删。

## 散文伪标签冒号禁令

散文自然段禁止「短名词话题 / 行内代码话题 + 全角冒号 + 解释」的词条式冒号（如 `` `Foo`：……``、`数组长度写成 X：……`）；这是列表项 `` `id`：职责 `` 的形态落进散文，版式像词条、读感怪异。命中改写成完整主谓句，或改真列表项。

冒号只保留两种合法场合：完整句引出紧随其后的列表、代码围栏或图（如「约定如下：」「定义在 state.h 里：」）；列表项引导词之后。其余散文冒号一律按词条式冒号处理。

判定信号：句首或句中出现「≤12 汉字话题或行内代码 + 全角冒号」，且该冒号没有引出列表/围栏/图。

豁免（不得误杀）：列表项（含 `` `enable_testing()`：开启 CTest。``）；列举/代码/图导语（下一块是列表、围栏或图）；终端与协议字面量（如 `流程结果：甲方获胜`）；表格单元格与代码注释。

与「破折号夹心改冒号引出」（见`conventions/writing/sentence-craft/sentence-limits.md` 的知识文件「句子规则」）的关系是**收窄**：破折号解释改冒号时，只允许改成上述两种合法场合，不允许改成散文词条式冒号。

## 拆核四步（多核混段的拆段方法）

同一自然段并行推进两个以上互不依赖的中心即为多核混段，读者分不清本段在讲什么。写作或改写涉及捆绑概念（如「长度 / 容器 / 坐标换算」）时，强制走四步：

1. **拆核**：列出本段必须交代的独立核（例：长度常量的含义；使用该长度的容器；行列到下标的换算）。
2. **判关系**：核是「属性 → 承载」递进还是并列。递进可同段用衔接推进（如长度定型 → 容器选用该长度，先长度后容器）；并列必须拆段。
3. **一句一核推进**：每句主语明确（长度 / 数组 / 换算），不夹第二个核的细节；禁止伪标签把两核糊成词条。
4. **衔接与次序**：段内用「因此 / 所以 / 这样」接住上句对象；换核新段时首句点名上段产物（例：先讲 `kRows`、`kCols` 给出合法范围，新段首句写「范围确定后，坐标检查才有了依据」；递进同一核的展开留在同一段，拆段判据见`conventions/writing/sentence-craft/sentence-frame.md` 的知识文件「句内骨架」）；若某核由后续小节专讲，本段只留一句明确桥接或整句下沉为其首句，禁止悬空预告。

拆段触发表已收录「词条式冒号 / 多核并列」信号行；改写对照见`knowledge/cases/chinese-style/paragraph-cases.md` 的知识文件「散文伪标签冒号与多核混段」。
